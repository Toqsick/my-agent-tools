# GE-Proton Compatibility

GE-Proton10-34 (Stand Juli 2026) kann mit CET-Inkompatibilitäten haben:
- Wenn CET-Konsole (`~` / `Insert`) nicht aufgeht → **GE-Proton downgraden**
- Bewährte Versionen: **GE-Proton9-7**, **GE-Proton8-31**
- Im Flatpak Steam: `Steam → Einstellungen → Kompatibilität → Erzwungene Kompatibilität`
- Oder per CLI: `PROTON_USE_WINED3D=1 %command%` (nur als Workaround)

CET-Konsole-Hotkeys:
| Taste | Funktion |
|---|---|
| `~` (Tilde) | CET-Konsole öffnen |
| `Insert` | Alternative (manchmal) |
| `F4` | Impel/PEG UI (falls Mod installiert) |
| `ESC` | CET-Konsole schließen |
