# Installations-Verzeichnisse

| Komponente | Target-Pfad (relativ zu CP77_ROOT) | Typ |
|---|---|---|
| RED4ext | `red4ext/RED4ext.dll` | File |
| CET (.asi) | `bin/x64/plugins/cyber_engine_tweaks.asi` | File |
| CET (Data) | `bin/x64/plugins/cyber_engine_tweaks/` | Dir |
| ArchiveXL | `red4ext/plugins/ArchiveXL/ArchiveXL.dll` | Dir |
| TweakXL | `red4ext/plugins/TweakXL/TweakXL.dll` | Dir |
| Codeware | `red4ext/plugins/Codeware/Codeware.dll` | Dir |
| RED4ext-Plugins | `red4ext/plugins/<ModName>/` | Dir |
| .archive Mods | `archive/pc/mod/` | Dir |
| .archive EP1 Mods | `archive/pc/ep1/mod/` | Dir |

**Case-Sensitivity:** RED4ext entpackt in `red4ext/` (kleines r), nicht `RED4ext/`. Sanity-Checks müssen case-insensitiv sein.
