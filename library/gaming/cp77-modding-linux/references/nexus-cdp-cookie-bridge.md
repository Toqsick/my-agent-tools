# Nexus-Cookie-Bridge via Chrome DevTools Protocol

**Zweck:** Nexus Mods verlangt Login. Cookies manuell zu exportieren ist mühsam. Dieser Workflow öffnet eine **separate Brave-Instanz mit Debug-Port**, lässt den User einmal einloggen, und holt die Session-Cookies via WebSocket/CDP.

**Wichtig:** Funktioniert nur für **Browser-interne Downloads**. Für curl-Downloads nach Cookie-Export siehe Pitfall #20 — Cloudflare blockt das wegen TLS-Fingerprint-Bindung.

## Voraussetzungen

- Brave installiert (`/usr/bin/brave-browser` oder Flatpak)
- Python `websockets` lib installiert (üblicherweise via `pip install websockets` im venv)
- Separate Debug-Brave darf laufen — stört normalen Brave NICHT

## Schritt 1: Separate Debug-Brave starten

```bash
# Eigener User-Dir = keine Kollision mit normalem Brave
DEBUG_DIR="/tmp/brave-debug-profile-nexus"
mkdir -p "$DEBUG_DIR"

# Background start
nohup /usr/bin/brave-browser \
  --user-data-dir="$DEBUG_DIR" \
  --remote-debugging-port=9333 \
  --remote-allow-origins='*' \
  --no-first-run \
  --no-default-browser-check \
  about:blank \
  > /tmp/brave-nexus-debug.log 2>&1 &

sleep 3
# Verify CDP reachable
curl -s "http://localhost:9333/json/version" | python3 -c "import json,sys; print('✅', json.load(sys.stdin)['Browser'])"
```

**Pitfall:** NICHT `pkill -f "remote-debugging-port"` — das killt auch Hermes-TUI. Siehe Pitfall #18.

## Schritt 2: User loggt sich ein

User öffnet das neue Brave-Fenster (sieht leer aus, kein Sync, kein Profil), geht auf `https://www.nexusmods.com/games/cyberpunk2077` und loggt sich ein. Avatar oben rechts = eingeloggt.

## Schritt 3: Cookies via CDP extrahieren

```python
import asyncio
import json
import websockets
from pathlib import Path
import urllib.request

# Hole WebSocket-URL des Page-Tabs
resp = urllib.request.urlopen("http://localhost:9333/json/list", timeout=5)
pages = json.loads(resp.read())
ws_url = next(p["webSocketDebuggerUrl"] for p in pages if p.get("type") == "page")

async def extract_cookies():
    async with websockets.connect(ws_url, max_size=10_000_000) as ws:
        await ws.send(json.dumps({
            "id": 1,
            "method": "Network.getCookies",
            "params": {"urls": ["https://www.nexusmods.com", "https://nexusmods.com"]}
        }))
        resp = json.loads(await ws.recv())
        cookies = resp.get("result", {}).get("cookies", [])

        # Filtere Nexus-Cookies
        nexus = [c for c in cookies if "nexus" in c.get("domain", "").lower()]

        # Speichere als Netscape-Cookie-Format
        cookie_file = Path.home() / "cp77-modding" / ".nexus-cookies.txt"
        cookie_file.parent.mkdir(parents=True, exist_ok=True)
        with open(cookie_file, "w") as f:
            f.write("# Netscape HTTP Cookie File\n")
            f.write("# Generated by Yuno via CDP — DO NOT SHARE\n\n")
            for c in nexus:
                domain = c["domain"]
                include_sub = "TRUE" if domain.startswith(".") else "FALSE"
                path = c.get("path", "/")
                secure = "TRUE" if c.get("secure", False) else "FALSE"
                expires = int(c.get("expires", -1)) if c.get("expires", -1) > 0 else 0
                f.write(f"{domain}\t{include_sub}\t{path}\t{secure}\t{expires}\t{c['name']}\t{c['value']}\n")

        print(f"✅ {len(nexus)} Cookies saved to {cookie_file}")
        return nexus

asyncio.run(extract_cookies())
```

## Warum NICHT die Brave SQLite-Cookies-DB direkt lesen?

Seit Brave v1.92+ ist die `value`-Spalte in `~/.config/BraveSoftware/Brave-Browser/Default/Cookies` **leer** (oder fehlt). Die echten Werte stehen in `encrypted_value` (AES-GCM verschlüsselt). Der Key kommt aus `Local State → os_crypt.portal` und ist seit neueren Versionen **portal-basiert** (Secret Service / KWallet), nicht mehr das alte `v10`/`v11`-Format.

**Praktisch:** Direkte DB-Extraktion ist nicht mehr zuverlässig machbar. CDP via separate Debug-Instanz ist der einzige funktionierende Weg.

## Was NICHT funktioniert (Lessons Learned)

| Methode | Warum scheitert |
|---|---|
| `curl --cookie .nexus-cookies.txt` | Cloudflare 403 (TLS-Fingerprint) |
| Direkte SQLite-Extraktion | `value` ist leer, `encrypted_value` braucht Portal-Key |
| API-Key statt Cookie | Braucht manuelle Generierung im User-Account |
| `requests`/`httpx` mit Cookies | Gleiche TLS-Fingerprint-Problematik wie curl |
| `Page.navigate` + `DOM.getOuterHTML` in Loop | 3-5 sec/Mod = 20-30 min für 444 Mods |

## Alternativen für Cloudflare-geschützte Downloads

- **Nexus API-Key** im Account generieren → funktioniert für saubere API-Calls (nicht Bulk-Downloads)
- **Browser-Extension** wie "Nexus Mod Downloader" — manuelle Klicks, kein Vortex
- **Manueller Klick** — User klickt durch, ZIPs landen in Downloads
