# Linux System Maintenance — Full Reference

Extracted from the `linux-system-maintenance` skill.

## Design Principles
1. **Safety-first:** Dry-run default, explicit confirmation for destructive ops
2. **Modular scanners:** Each cleanup domain implements `BaseScanner`
3. **Rich TUI:** Use `rich` for tables, panels, progress
4. **Configurable:** JSON config drives active scanners + whitelist
5. **Backup before delete:** Move to `~/.yuno-cleaner/backups/<timestamp>/`

## Architecture
```
cleanup_tool/
├── main.py              # argparse entrypoint
├── modules/
│   ├── base_scanner.py  # ABC with scan()
│   ├── system_junk.py   # APT, journalctl, thumbnails
│   ├── browser_cache.py # Chrome, Brave, Firefox
│   ├── gaming_junk.py   # Steam, Epic, Mesa shaders
│   ├── duplicate_finder.py
│   └── large_files.py
├── ui/tui.py            # rich Console

└── config/default.json
```

## Common Cleanup Targets
| Target | Path | Root? | Notes |
|--------|------|-------|-------|
| APT cache | `/var/cache/apt/archives/*.deb` | ✅ | `apt clean` is safer |
| journalctl | `/var/log/journal/` | ✅ | `--vacuum-time=7d` |
| Thumbnails | `~/.cache/thumbnails` | ❌ | Safe to delete entirely |
| pip cache | `~/.cache/pip` | ❌ | `pip cache purge` |
| Chrome cache | `~/.config/google-chrome/Default/Cache` | ❌ | Close browser first |
| Steam shadercache | `steamapps/shadercache` | ❌ | 10-50 GB |
| npm cache | `~/.npm/_cacache/` | ❌ | 1-2 GB |
| Snap revisions | `snap list --all` disabled | ❌ | Remove old revisions |

## CLI UX Pattern
- `scan` → always dry-run, shows tables
- `clean` → dry-run unless `--execute`, requires "JA" confirmation
- `--json` → machine-readable output (use `console.quiet = True` for rich compatibility)

## Cleanup Execution Order
1. No-sudo first (user-writable caches)
2. Large data (downloads, game files)
3. Sudo cleanups (apt, journal, kernel purge)
4. Document results to `~/docs/system/`

## rc Package Purge (Critical Ordering)
```bash
# 1. Identify rc packages
dpkg -l | grep '^rc' | awk '{print $2}'

# 2. Purge old kernels FIRST
sudo dpkg --purge linux-image-<old>-generic

# 3. Then kernel modules + extras
sudo dpkg --purge linux-modules-* linux-modules-extra-*

# 4. Then NVIDIA old-driver modules
sudo dpkg --purge $(dpkg -l | grep '^rc' | grep -E 'nvidia-(570|580)' | awk '{print $2}')

# 5. Clean orphaned module dirs
sudo rm -rf /lib/modules/<old-version>-generic

# 6. All remaining rc packages
dpkg -l | grep '^rc' | awk '{print $2}' | xargs sudo dpkg --purge
```

## steam-installer Purge Workaround
```bash
sudo rm -f /var/lib/dpkg/info/steam-installer.postrm
sudo rm -f /var/lib/dpkg/info/steam-installer.prerm
sudo dpkg --purge --force-all steam-installer
```

## Manual System Inspection
```bash
# 1. Quick health
df -h / /home && free -h && sensors | head -20 && uptime

# 2. Package & kernel audit
apt list --upgradable 2>/dev/null | head -30
dpkg -l | grep -E 'linux-(image|headers|modules)'
dpkg -l | grep '^rc' | wc -l

# 3. Log & cache audit
journalctl --disk-usage
du -sh /var/cache/apt/ ~/.npm/ ~/.cache/pip/

# 4. Mail client check
dpkg -l | grep -iE "thunderbird|evolution|kmail"

# 5. Home dirs by size
du -sh ~/*/ 2>/dev/null | sort -rh | head -15
```

## Kernel Cleanup Rule
Keep only **current kernel** (`uname -r`) plus **one backup**. Purge all others including rc-state configs.

## Pitfalls
1. Never recurse into `~/.ssh/`, `~/.gnupg/`, `~/.config/` blindly
2. Browser caches only when browser is closed
3. Steam shadercache regenerates — warn user
4. `apt autoremove --purge` does NOT clean rc packages — use `dpkg --purge`
5. `shutil.disk_usage` has no `.percent` attribute — calculate manually
6. Backtick characters inside f-strings break Python syntax
7. `execute_code` preferred over `patch` for complex multi-line edits
8. **`apt autoremove` does NOT remove the previous HWE kernel** — Ubuntu HWE marks the prior kernel as manually-installed, so autoremove returns "0 zu entfernen". To remove a specific old kernel, list the packages explicitly:
   ```bash
   sudo apt purge -y \
     linux-image-<OLD>-generic \
     linux-headers-<OLD>-generic \
     linux-modules-<OLD>-generic \
     linux-modules-extra-<OLD>-generic
   ```
   The matching `linux-modules-nvidia-*` package stays (it follows the running kernel, not the old one). Always run `uname -r` first to confirm the active kernel. GRUB and initramfs are auto-regenerated by the postrm hook.
9. **Brave browser cache path** uses spaces and a versioned directory: `~/.cache/BraveSoftware/Brave-Browser/Default/Cache/` and `Code Cache/`. Quote the `Code Cache` segment or escape the space. Clearing is safe; Brave rewrites it on next launch.
