### 4. AI-Feel-Problem: 7 Human-Touches nach Bulk Create

| Touch | Canva-Umsetzung |
|---|---|
| Abweichende Textgröße | 1–2 Schlüsselwörter/Slide bewusst 20% größer |
| Mikro-Rotation | Textelemente um ±1,5° rotieren |
| Handschrift-Annotation | Caveat/Patrick Hand Font auf Card 3–5 |
| Slide-spezifische Helligkeit | 1 Slide 10% heller als Rest |
| Durchstreichung | `~~Sparen~~ → Investieren` |
| Eigene Slide-Nummerierung | `01/07`, `02/07` statt Auto-Counter |
| Asymmetrisches Padding | Text 20px links statt zentriert |

**Action-Item:** Workflow-Regel: nach Bulk Create **3–4 dieser Touches manuell setzen** pro Post.

### 5. Slide-4-Trick + neue Save-Trigger-Phrasen

**Slide-4-Trick:** Auf Card 1 hinweisen „Slide 4 ist der Schlüssel" — erzwingt Swipes, erhöht Completion Rate.

**Save-Trigger-Phrasen für Card 6–7:**
- „Speicher das — du brauchst es wieder"
- „Bookmark das für [Steuersaison/Jobwechsel/nächste Gehaltsverhandlung]"
- „Schick das an jemanden der das braucht" (Share-Indikator)
- „Das willst du wiederfinden können"

**Action-Item:** In `pitch-variants.json` als neue `variants` aufnehmen (`type: save-trigger` + `best_for`).

### 6. Hashtag-Update — nur 3–5 statt 20+

**Konsens 2026:** 3–5 Hashtags pro Post > 20+ generische. TikTok ist primär Suchmaschine — On-Screen-Text und Caption-Keywords wichtiger.

| Position | Anzahl | Beispiele |
|---|---|---|
| Broad (500K–2M Posts) | 1 | `#finanztipps`, `#produktivitätstipps` |
| Nische (50K–200K) | 1–2 | `#kreditkartentipps`, `#deepwork` |
| Micro-Nische (5K–30K) | 1 | `#kreditkartenvergleich` |
| EN-Crossover (optional) | 1 | `#creditcardhacks`, `#productivitytips` |

**Wertlos:** `#fyp`, `#fürdich`, `#viral`, `#trending`
**Aktiv schädlich:** Irrelevante Hashtags, kontroverse Tags, >7 Hashtags

### 7. Save-Rate-Benchmarks (Konsens aller 3 Reports)

| Save-Rate | Interpretation | Action |
|---|---|---|
| <0,25% | Content wird nicht referenziert | Hook komplett neu |
| 0,25–1% | Akzeptable Baseline | Format iterieren |
| 1–2% | Stark | Verdoppeln |
| 2–5% | Exzellent | Skalieren |
| **5%+** | **Nische funktioniert** | **Produkt launchen** |
| 10%+ | Save-Magnet | Preis erhöhen |

**Für unseren 14-Tage-Test:** ≥3% Save-Rate über 5+ Posts = strong signal. <1% über 10+ Posts = Nischen-Problem (nicht Hook-Problem).
