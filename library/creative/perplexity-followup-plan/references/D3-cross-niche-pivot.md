# D3 — Cross-Niche-Pivot-Test

> **Trigger:** Erste Nische stabilisiert sich, du willst Account #2 launchen.
> **Wann:** Monat 3-4 (wenn Account #1 bei 5-10k Followern stabil läuft).
> **Ziel:** 2. Nische finden, die Account #1 ergänzt statt kannibalisiert.

## Wann diese Frage stellen

✅ Account #1 hat 5-10k+ Follower stabil
✅ Du hast Lust auf Account #2 (oder Cross-Promo zu Account #1)
✅ Du hast 10-15 Std/Woche zusätzliche Content-Production-Kapazität
❌ NICHT vor Account #1-Stabilisierung — zwei Accounts gleichzeitig aufbauen ist die häufigste Sünde
❌ NICHT wenn du bei Account #1 noch Save-Rate-Probleme hast (B2 nochmal)

## Daten die du mitgeben musst

- Account #1 Nische + aktuelle Follower-Zahl + aktuelle Performance
- Welche Themen-Clusters Account #1 abdeckt
- Audience-Demographics (wenn bekannt: Alter, Geschlecht, Interessen)
- Optional: Welche Nischen dich selbst interessieren

## Prompt (1:1 in Perplexity Deep Research einfügen)

```
My main account `@[winner]` is at [X] followers, [Y] monthly revenue. Now I want to launch account #2 in a complementary niche.

Help me pick the 2nd niche using this decision-tree:
1. Which niches share the SAME audience as my first (so I can cross-promote) but DON'T cannibalize the first niche?
2. Which niches use the SAME content template I've already mastered (so I don't re-learn)?
3. Which niches are 2026 up-and-coming (TikTok Creative Center "rising" filter) but NOT yet saturated?
4. Should I run a 2nd faceless account, or run 2 niches on the SAME account? (TikTok's audience-graph algorithm — does it penalize topic-mixing?)

Give me 3 concrete "niche-pair" recommendations where the math compounds (cross-promo, shared audience, shared production workflow).
```

## Output-Format von Perplexity erwartet

- Audience-Overlap-Analyse zwischen Account #1 und 5-10 Kandidaten-Nischen
- 3 Niche-Pair-Empfehlungen mit Cross-Promo-Mechanik
- Same-Account vs Two-Accounts-Entscheidung mit Algorithmus-Evidenz

## Was du mit der Antwort machst

1. **3 Niche-Pair-Empfehlungen** in `docs/strategie/account-2-candidates.md` speichern
2. **Entscheidung** treffen: Two-Account-Strategy oder Same-Account-Mix
3. **Bei Two-Account**: 2. Account-Setup planen (neues Brand-System, neuer Test-Plan)
4. **Cross-Promo-Strategie**: Wie Account #1 → Account #2 verlinken ohne Shadowban-Risiko
5. **Production-Workflow-Sharing**: Welche Tools/Prompts/Scripts für beide Accounts nutzbar sind (z.B. `tiktok-design-assistant` Skill für beide)

## Pitfalls

- **Audience-Overlap ≠ Cross-Promo-Permission**: Auch wenn Account #1 = "Kreditkarten" und Account #2 = "Geld sparen" ähnliche Audience haben — direkte Cross-Promo ("schau mein anderes Konto") triggert möglicherweise Spam-Filter. Indirekte Methoden besser.
- **Template-Sharing ≠ Content-Sharing**: Gleicher Hook-Template ist OK. Gleiche Posts duplizieren ist Schatten-Spam.
- **Same-Account-Mix-Algorithmus**: TikTok testet Audience-Reaktion auf gemischte Topics. Wenn 80% deiner Audience auf "Kreditkarten" engagiert, aber 20% auf "Geld sparen", mischt TikTok das irgendwann. Frage ist: ist das gut oder schlecht für Reichweite?
- **Burnout**: 2 Accounts = 2× Content-Production. Realistisch kalkulieren.
