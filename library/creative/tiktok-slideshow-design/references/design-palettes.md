# Design-Paletten für TikTok-Slideshows (DE-Sprachraum)

> 3 ausgearbeitete Farbschemata + Font-Pairings für Top-Nischen.

## Palette 1: Trust & Calm
**Am besten für:** Finance, Kreditkarten, Steuern, ETF/Sparplan

```
┌────────────────────────────────────────────┐
│ 🎨 TRUST & CALM                             │
│                                             │
│ Primary:     #1A2B47  (Deep Navy)          │
│ Secondary:   #D4AF37  (Soft Gold)          │
│ Accent:      #E8EDF2  (Cool White)         │
│ Neutral D:   #2C3E50  (Slate)              │
│ Neutral L:   #F5F7FA  (Mist)               │
│                                             │
│ WCAG-Kontrast:                              │
│   Primary on Neutral L  → 11.2:1 ✅        │
│   Accent on Primary     → 8.5:1 ✅         │
│   Secondary on Primary  → 4.8:1 ✅         │
│                                             │
│ Fonts:                                      │
│   Headline: "Anton" (Bold, 48-72pt)        │
│   Body:     "Open Sans" (Regular, 24pt)    │
│   Caption:  "IBM Plex Mono" (12pt)         │
│                                             │
│ Usage-Rules:                                │
│   Primary für: Slide-Backgrounds           │
│   Secondary für: Akzente, Zahlen, Hervorhebungen │
│   Accent für: Text auf Primary Background  │
│   Neutral D für: Body-Text                  │
│   Neutral L für: Alternating Slide-BG      │
└────────────────────────────────────────────┘
```

**Farbsymbolik:**
- Deep Navy = Stabilität, Vertrauen, Professionalität (Standard-Bank-Farbe)
- Soft Gold = Wert, Exklusivität, Premium (hebt Zahlen hervor)
- Cool White/Mist = Lesbarkeit, Klarheit, Seriosität

**Wann NICHT:**
- Lifestyle-Nischen (zu seriös, zu "Bank-Sprech")
- Mental-Health (zu kalt)
- Minimalismus (zu viele Farben)

## Palette 2: Soft Power
**Am besten für:** Lifestyle, Selbstoptimierung, Mental Health, Produktivität, Side-Hustle

```
┌────────────────────────────────────────────┐
│ 🎨 SOFT POWER                               │
│                                             │
│ Primary:     #6B7C5F  (Sage Green)         │
│ Secondary:   #C89B7B  (Warm Beige)         │
│ Accent:      #D9534F  (Coral Red — CTA)    │
│ Neutral D:   #3A3A3A  (Charcoal)           │
│ Neutral L:   #FAF6F2  (Cream)              │
│                                             │
│ WCAG-Kontrast:                              │
│   Primary on Neutral L  → 3.8:1 ⚠️         │
│   Accent on Neutral L   → 4.2:1 ✅         │
│   Neutral D on Neutral L → 12.5:1 ✅       │
│   (Sage Green auf Cream für Headlines zu       │
│    schwach — Headlines immer in Charcoal)      │
│                                             │
│ Fonts:                                      │
│   Headline: "Playfair Display" (Bold)      │
│   Body:     "Inter" (Regular)              │
│   Caption:  "Inter" (Light, Italic)        │
│                                             │
│ Usage-Rules:                                │
│   Primary für: Headline-Akzente, Zahlen    │
│   Secondary für: Warme Backgrounds         │
│   Accent für: CTA-Button, Slide-1-Headline │
│   Neutral D für: Haupttext (immer!)         │
│   Neutral L für: Default-Slide-Background  │
└────────────────────────────────────────────┘
```

**Farbsymbolik:**
- Sage Green = Natürlichkeit, Wachstum, Gelassenheit (kein "Finance-Druck")
- Warm Beige = Geborgenheit, Wärme, Alltagsnähe
- Coral Red = Dringlichkeit, Action (sparsam einsetzen — nur für CTAs)

**Wann NICHT:**
- Finance/Kreditkarten (wirkt nicht "trusted")
- BookTok (zu wenig dramatisch)

## Palette 3: Clean Focus
**Am besten für:** Minimalismus, BookTok, Produktivität, Capsule Wardrobe, DIY

```
┌────────────────────────────────────────────┐
│ 🎨 CLEAN FOCUS                              │
│                                             │
│ Primary:     #000000  (Pure Black)          │
│ Secondary:   #FFFFFF  (Pure White)          │
│ Accent:      #FF6B35  (Energetic Orange)   │
│ Neutral D:   #1A1A1A  (Near Black)         │
│ Neutral L:   #F0F0F0  (Light Gray)         │
│                                             │
│ WCAG-Kontrast:                              │
│   Primary on Secondary → 21:1 ✅✅          │
│   Accent on Primary    → 6.8:1 ✅           │
│   Accent on Secondary → 3.2:1 ⚠️           │
│   (Orange auf Weiß ist zu schwach für Text —│
│    nur für grafische Akzente verwenden!)    │
│                                             │
│ Fonts:                                      │
│   Headline: "Montserrat" (Black, 60-84pt)  │
│   Body:     "IBM Plex Sans" (Regular)      │
│   Numbers:  "IBM Plex Mono" (Bold)         │
│                                             │
│ Usage-Rules:                                │
│   Primary für: Backgrounds, Headlines       │
│   Secondary für: Text auf Black            │
│   Accent für: Grafische Elemente, Icons     │
│   Neutral D für: Slide 1 Subtext            │
│   Neutral L für: Alternating Backgrounds    │
└────────────────────────────────────────────┘
```

**Farbsymbolik:**
- Pure Black = Klarheit, Fokus, "Null Overhead"
- Pure White = Reduktion, Minimalismus
- Energetic Orange = Energie, Kreativität (aber nur als Akzent)

**Wann NICHT:**
- Finance (zu dramatisch, wirkt unseriös)
- Mental-Health (zu aggressiv)
- Schlaf-Optimierung (schwarz = nachts = nicht beruhigend)

## Font-Quick-Reference

| Font | Gewicht-Verfügbar | Stimmung | Am besten für |
|---|---|---|---|
| **Anton** | Bold only | Kraftvoll, männlich, dominant | Finance, Listen-Pattern |
| **Open Sans** | Light-Bold | Neutral, seriös, gut lesbar | Allround-Body-Font |
| **Playfair Display** | Regular-Black | Elegant, weiblich, zeitlos | Lifestyle, Mental Health |
| **Inter** | Thin-Black | Modern, neutral, funktional | Body-Font für die meisten |
| **Montserrat** | Thin-Black | Modern, clean, vielseitig | Headlines, Clean Focus |
| **IBM Plex Sans** | Regular-Bold | Technisch, klar, lesbar | Body-Font, Zahlen |
| **IBM Plex Mono** | Regular-Bold | Technisch, präzise | Caption, Daten |

**Fallback-Chain:** `font-family: "Primary", "Secondary", sans-serif;`

## Canva-Template-Tipps

### Template-Struktur für Bulk-Create

| Feld | Canva-Platzhalter | Typ |
|---|---|---|
| post_id | `{{post_id}}` | Text |
| slide_1_headline | `{{slide_1}}` | Text (groß, caps) |
| slide_2_text | `{{slide_2}}` | Text (body) |
| slide_3_text | `{{slide_3}}` | Text (body) |
| pitch | `{{pitch}}` | Text (CTA) |
| background_image | `{{image}}` | Image |

### Canva Bulk-Create Einschränkungen
- Max 10 Spalten (bei mehr aufteilen)
- Max 500 Zeilen pro Upload
- CSV UTF-8 mit Anführungszeichen
- Bilder via URL in separater Spalte
- Template vor Bulk-Create in Canva testen (leere Slides)

### Stock-Photo-Quellen (Canva Premium)
- Canva Magic Media (eingebaut, kostenfrei mit Pro)
- Unsplash (via Canva)
- Pexels (via Canva)
- Pixabay (via Canva)

**Tipp:** Keine Stock-Photos die wie Stock aussehen. Makro-Aufnahmen, Flat-Lays und Textur-Fotos wirken authentischer als offensichtliche Stock-Szenen.
