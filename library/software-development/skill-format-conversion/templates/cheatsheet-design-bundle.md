## 🔁 Workflow-Kombos

### 🏷️ Brand Identity aus Screenshot

```
1. Bild in Chat laden → vision_analyze analisiert Style
2. /ui-color-system → WCAG-Palette generieren
3. /ui-design-system → Komplette Tokens
4. /ui-component-library → Components scaffolded
5. /html-artifact → Style-Guide-Page
```

### 🏠 Landing Page mit Brand Voice

```
1. /landing-page-builder <konzept>
2. /ui-ux-pro-max review → Design-Audit
3. /humanizer tone der copy → Falls AI-sounding
4. /seo-geo-optimization-expert → SEO-Optimierung
```

### 📈 Dashboard aus Daten

```
1. /ui-dashboard <data-schema>
2. /visual-content-generator charts → Custom Charts
3. /architecture-diagram <layers> → Architecture Overview
```

### 🎬 Kurz-Video / Ad

```
1. /film-shot <script> → Storyboard (8 Styles)
2. /video-prompting → Optimierte Prompts für PixVerse
3. /image_generate → Storyboard-Bilder als Referenz
4. /video_generate → Animation
5. /text_to_speech → Voice-Over
6. /heartmula oder /songwriting-and-ai-music → Background-Music
```

### 🎨 Anime Character Pack

```
1. /anime-design <char-desc> → Main Character (14 Styles)
2. /anime-style-forge <ref-image> → Style-Convert
3. /image_generate <expression poses> → Expression Sheet
4. /ui-ux-pro-max character-card → Card-Layout
```

### 📚 PPT-Deck (McKinsey-Style)

```
1. /mckinsey-presentation-generator <topic>
2. /visual-content-generator data-charts → Custom Charts
3. /humanizer narrative → Strip AI-speak
4. /architecture-diagram → Wenn Tech-Topic
```

### 🪪 Logo-Set

```
1. /icon-maker <konzept> → 5 Style-Varianten
2. /image_generate refinement → Best-Variante ausarbeiten
3. /html-artifact brand-guidelines → Brand-Page
```

### 🎓 Lern-Material aus PDF

```
1. PDF upload → /knowledge-digest → Multimodale Materials
2. /ui-dashboard quiz-layout → Quiz-Page
3. /text_to_speech → Audio-Course
```
