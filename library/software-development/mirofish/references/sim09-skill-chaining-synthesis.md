## 5 Engineering Take-Aways for Hermes V7

1. **3 Skill-Schichten unterstützen:** None-Skill (frische Generierung, 5-8 Min teurer), Template-Skill (Form-only, 1-2 Min günstiger), Derived-Skill (Inhalt+Form, ~0 Min Setup, aber ~100% Findings-Inheritance)
2. **`bias_disclosure`-Header MUSS mandatory im Derived-Skill** — sonst ist Skill-Vererbung Audit-fail
3. **80% Jaccard-overlap als standardisierte Bias-Metrik** — unter 80% = neue Insights, drüber = Reproduktion
4. **Provenance-Chain im Skill-Header** — welche Original-Runs haben Findings geliefert? Macht Skills rückführbar auditierbar
5. **WIP-Limit: max. 3 Generationen pro Derived-Skill** — Run C reproduziert 62-78% der Prio Findings (NeurIPS-Estimate), bei >3 Generationen würde Bias explodieren
