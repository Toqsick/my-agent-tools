# Research Paper Generator

## Overview

This skill orchestrates the complete production of a doctorate-level research paper (12,000-15,000 words) delivered as a professionally formatted Word document (.docx). It performs ten sequential phases: initialization, research planning, literature acquisition, synthesis, framework development, data analysis (if empirical), writing, quality assurance, and technical production, followed by final delivery. Each phase has strict quality gates that must pass before proceeding.

## Workflow

### Phase 1: Initialization

1. **Receive the user's research topic or request.** Acknowledge receipt warmly and professionally.

2. **Immediately ask the user to select their preferred citation system** before anything else. Present these options:
   - APA 7th Edition (Psychology, Education, Social Sciences)
   - MLA 9th Edition (Humanities, Literature)
   - Chicago 17th Edition (History, Humanities)
   - Harvard Style (Business, Economics)
   - IEEE Style (Engineering, Computer Science)
   - Vancouver Style (Medical Sciences)
   - Other (user specifies)

3. **Tell the user you will research the latest official citation rules online** and apply them throughout the document.

4. **Wait for the user's citation system selection.** Do not proceed until you have this.

5. **Record the citation system selection** for use throughout the project.

6. **Begin citation system research** (see [Citation System Research](#citation-system-research)) while continuing to gather requirements.

7. **Ask clarifying questions** to understand the research topic completely:
   - What is the specific research topic or question?
   - What discipline or field is this for?
   - Is this empirical research (with original data analysis) or theoretical research (literature-based)?
   - Are there any specific requirements (length, format, sections)?
   - What is the desired timeline?
   - Any other special requirements?

8. **Confirm with the user** that you will produce ONLY a Word document (.docx), not a PDF.

9. **Analyze the user's responses** to determine:
   - Primary discipline(s)
   - Research type (empirical vs. theoretical)
   - Complexity level
   - Required components
   - Timeline feasibility

10. **Complete citation system research.** Verify the citation guide includes:
    - In-text citation formats with examples
    - Reference list formats for all source types
    - Special cases documentation
    - Common errors to avoid

11. **Store the citation guide** for use in all subsequent writing and review steps.

12. **Create a project plan** that includes:
    - All phases mapped out
    - Expected timeline for each phase
    - Quality standards for each deliverable
    - Decision on whether Phase 6 (Data Analysis) is needed
    - Identification of steps that can be combined

13. **Communicate the project plan to the user** with estimated timeline and confirm they approve.

14. **Proceed to Phase 2** only after: citation system researched, requirements clear, project plan created, and user approval received.

**Quality Gate 1:**
- Topic well-defined
- Citation system selected and researched
- Scope established
- All questions answered

## Critical Rules

### Never Skip Quality Gates
- Quality gates are non-negotiable checkpoints. Never proceed to the next phase until output passes the quality gate.
- If a quality gate fails repeatedly (more than 3 attempts): reassess the approach, provide more detailed guidance, consider whether requirements need adjustment, consult with user if scope issues arise.

### Execution Order
- **Strictly sequential**: Phases 1 through 10 must execute in order.
- Phase 6 is conditional (empirical research only).
- Never write before synthesis is complete.
- Never review quality before writing is complete.
- Never format before quality approval.

### Quality Standards
Every deliverable must meet doctorate-level academic standards:
- Comprehensive coverage of literature (50-100+ sources)
- Rigorous methodology (if empirical)
- Clear, sophisticated theoretical framework
- Excellent writing quality (clear, precise, well-organized)
- Perfect citation accuracy (100% compliance with chosen system)
- Professional formatting throughout
- No errors of any kind

### Document Output
- Output format: Word document (.docx) ONLY. No PDF.
- Target length: 12,000-15,000 words.

## Research Planning & Topic Analysis

### Topic Deconstruction

- Break down research topic into core concepts
- Identify implicit and explicit elements
- Extract key variables, phenomena, themes
- Recognize theoretical foundations
- Determine inquiry type and scope

### Disciplinary Contextualization

- Identify primary academic discipline(s)
- Recognize interdisciplinary connections
- Position within broader field(s)
- Understand disciplinary conventions

### Research Question Formulation

- Develop 1-3 clear, focused research questions
- Ensure questions are answerable and well-framed
- Align with feasible methodologies

### Scope Definition

- Temporal boundaries
- Geographical/cultural boundaries
- Population parameters
- Conceptual boundaries
- Inclusion/exclusion criteria

### Search Strategy Development

**Keyword Generation (minimum 30-50):**
- Core concept keywords
- Synonyms and related terms
- Discipline-specific terminology
- Variant spellings
- Historical and contemporary terms
- Organized by concept clusters

**Boolean String Construction (5-10 strings):**
- AND (narrow, combine concepts)
- OR (broaden, include synonyms)
- NOT (exclude irrelevant)
- Nested queries with parentheses
- Example: `(climate OR "climate change" OR "global warming") AND (policy OR legislation) AND (adaptation OR mitigation) NOT (denial OR skeptic)`

**Database Identification (10-15 recommendations):**

Primary multidisciplinary:
- Web of Science
- Scopus
- Google Scholar

Discipline-specific (select based on topic):
- PubMed/MEDLINE (medical/life sciences)
- PsycINFO (psychology)
- IEEE Xplore (engineering/computer science)
- ERIC (education)
- EconLit (economics)
- PhilPapers (philosophy)
- Sociological Abstracts (sociology)
- MLA Bibliography (literature/languages)
- JSTOR (humanities/social sciences)

Supplementary:
- ProQuest Dissertations & Theses
- arXiv, SSRN, bioRxiv (preprints)
- Institutional repositories
- Government publications
- Conference proceedings

### Special Considerations by Topic Type

**Interdisciplinary Topics:** Identify all relevant disciplines, recognize different terminologies, bridge paradigmatic differences, plan multi-disciplinary search.

**Applied Topics:** Connect theory and practice, identify practitioner perspectives, include implementation contexts.

**Controversial Topics:** Identify perspectives objectively, recognize politically charged elements, plan balanced treatment.

**Emerging Topics:** Acknowledge limited research, identify related established fields, plan innovative approaches.

## Literature Discovery & Evaluation

### Search Execution

For each database:
- Use Boolean strings from search strategy
- Apply appropriate filters (date, peer-review, etc.)
- Document query and results count
- Export citations and PDFs
- Note any issues encountered

### Citation Tracking
- Identify 5-10 most cited/influential papers
- Forward citation search (who cites them)
- Backward citation search (their references)
- Map citation networks

### Search Techniques

**Wildcards & Truncation:**
- `*` (multiple characters): child* = child, children, childhood
- `?` (single character): wom?n = woman, women

**Field Searching:**
- TI: (title), AB: (abstract), AU: (author), KW: (keywords)

### Quality Evaluation Scoring

For each source, assess on these dimensions:

**Authority (0-40 points):**
- Author credentials (0-10)
- Institutional affiliation quality (0-10)
- Author expertise in topic (0-10)
- Publication track record (0-10)

**Credibility (0-40 points):**
- Peer review quality (0-10)
- Publisher reputation (0-10)
- Indexing status (Web of Science, Scopus) (0-10)
- Freedom from serious bias (0-10)

**Quality (0-40 points):**
- Methodological rigor (0-10)
- Evidence strength (0-10)
- Analytical soundness (0-10)
- Limitations acknowledged (0-10)

**Relevance (0-20 points):**
- Alignment with research questions (0-10)
- Contribution to understanding (0-10)

**Currency (0-20 points):**
- Timeliness (0-10)
- Not superseded by better work (0-10)

**Total: /160 (convert to percentage)**

### Source Prioritization Tiers

| Tier | Label | Criteria | Action |
|------|-------|----------|--------|
| 1 | Essential | Score >= 70% AND high relevance; seminal/foundational works | Must include |
| 2 | Important | Score 60-69% AND substantial relevance | Should include |
| 3 | Supplementary | Score 50-59% OR moderate relevance | Include if space allows |
| 4 | Optional | Score < 50% OR minimal relevance | Include selectively |
| Excluded | -- | Poor quality (<40%), retracted, predatory | Do not use |

### Special Checks
- Check RetractionWatch database

### Saturation Indicators
- New searches return mostly already-found sources
- Citation tracking circles back to known works

- All major authors identified

## Synthesis & Critical Analysis

### Systematic Reading Protocol

**For Tier 1 Sources (Essential):**

First Pass (15 min): Read abstract, intro, conclusion. Skim methodology. Identify main contribution. Tag initial themes.

Second Pass (30-45 min): Read full text carefully. Extract key arguments. Document main findings with evidence. Identify methodology. Note theoretical assumptions. Extract quotations with page numbers. Provide critical assessment.

**For Tier 2 Sources:** Slightly less intensive. Focus on key contributions and relationship to Tier 1 sources.

### Thematic Coding

**Initial Coding:**
- Create codes inductively (emerging from data)
- Create codes deductively (from research questions)
- Define each code clearly
- Establish coding rules

**Iterative Coding:**
- Apply codes systematically
- Refine, merge, and split codes as needed
- Create hierarchical structure
- Group codes into 5-10 major themes

### Comparative Analysis Matrices

**Findings Comparison:**
| Author (Year) | Research Q | Method | Sample | Key Findings | Limitations | Quality |

**Theoretical Comparison:**
| Author | Framework | Key Concepts | Assumptions | Scope | Contribution | Critique |

**Methodological Comparison:**
| Author | Design | Data Collection | Analysis | Validity | Strengths | Weaknesses |

### Critical Evaluation

**For Quantitative Studies:** Design appropriateness, sampling adequacy, measurement validity/reliability, statistical analysis soundness, generalizability, causal claims justification, confound control.

**For Qualitative Studies:** Credibility, transferability, dependability, confirmability, data collection appropriateness, analytical transparency, researcher reflexivity, theoretical saturation.

**Bias Detection:** Selection bias, confirmation bias, publication bias, funding/conflict of interest bias, cultural/ideological bias, methodological bias, selective reporting.

### Gap Analysis Categories

- **Empirical gaps:** Understudied populations, unexplored contexts, unmeasured variables, untested relationships
- **Theoretical gaps:** Unexplained phenomena, undertheorized areas, contradictions requiring resolution
- **Methodological gaps:** Methods not yet applied, measurement/design limitations, analytical innovations needed
- **Practical gaps:** Unstudied applications, policy areas needing research

### Synthesis Output Structure

1. Executive Summary (1,000 words)
2. Thematic Synthesis (5,000-7,000 words) - one section per theme
3. Chronological Development (1,000 words)
4. Theoretical Synthesis (1,000-1,500 words)
5. Methodological Synthesis (1,000 words)
6. Critical Evaluation (1,000-1,500 words)
7. Gap Analysis (1,000 words)
8. Positioning of Current Research (500 words)

## Theoretical & Methodological Framework

### Theory Selection Criteria

Evaluate theory options on:
- Relevance to research questions
- Explanatory power
- Empirical support
- Methodological compatibility
- Appropriate abstraction level
- Disciplinary acceptance
- Innovation potential

### Theory Types
- Grand theories (high abstraction, broad scope)
- Middle-range theories (moderate abstraction)
- Substantive theories (specific phenomena)
- Grounded theories (data-emergent)
- Borrowed theories (from other disciplines)
- Integrated frameworks (multiple theories)

### Concept Definition Format

For each key concept:

**Conceptual Definition:** Clear definition grounded in theory and literature, with citation.

**Operationalization** (if empirical): How concept will be measured/observed, specific indicators, measurement procedures.

**Justification:** Why this definition is chosen, alignment with theoretical tradition, validation in prior research.

**Related Concepts:** How it relates to and differs from other concepts.

### Conceptual Model Types
- Causal models (X -> Y)
- Process models (stages/sequences)
- Typologies (categorical classification)
- Hierarchical models (nested levels)
- Network models (interconnected elements)
- Integrated models (multiple frameworks)

### Methodology Design (If Empirical)

**Research Design Options:**

Quantitative: Experimental, quasi-experimental, survey, correlational, longitudinal, cross-sectional.

Qualitative: Phenomenology, grounded theory, ethnography, case study, narrative inquiry.

Mixed Methods: Convergent parallel, explanatory sequential, exploratory sequential, embedded design.

**Sampling Strategy:**
- Population definition
- Sampling method and justification
- Sample size calculation (power analysis for quantitative; saturation rationale for qualitative)
- Inclusion/exclusion criteria
- Recruitment procedures

**Data Collection:**
- Methods/instruments with psychometric properties
- Procedures detailed enough for replication
- Pilot testing plan
- Quality control measures

**Analytical Techniques:**
- Specific tests/approaches named
- Software with version numbers
- Assumption testing procedures
- Significance level specification

**Validity & Reliability:**
- Internal/external/construct validity (quantitative)
- Credibility/transferability/dependability/confirmability (qualitative)
- Triangulation plans

### Ethical Review

- IRB/Ethics committee approval plan
- Risk assessment and mitigation
- Informed consent procedures
- Privacy and confidentiality measures
- Data security and retention
- Vulnerable populations protections (if applicable)
- Responsible research practices

### Assumptions & Scope

- State all theoretical and research assumptions explicitly
- Justify each assumption
- Define scope conditions (temporal, spatial, population, contextual, conceptual)
- Specify boundary conditions and generalizability parameters
- Acknowledge limitations honestly

## Data Analysis & Visualization (Empirical Research Only)

### Quantitative Analysis Steps

1. **Data Preparation:** Import, check structure, recode variables, handle missing data, check outliers, create composites, generate descriptive statistics, check distributions.

2. **Descriptive Statistics:** Frequencies/percentages (categorical), means/SDs/ranges (continuous), correlations. Create Table 1: Sample Characteristics.

3. **Assumption Testing:** Normality (Shapiro-Wilk, Q-Q plots), homogeneity of variance (Levene's), independence, linearity, multicollinearity (VIF), sphericity (Mauchly's). Document violations and how addressed.

4. **Primary Analyses:** Execute planned tests (t-tests, ANOVA, regression, SEM, factor analysis, etc.). For each: record test statistics, p-values, effect sizes, confidence intervals, degrees of freedom.

5. **Post-Hoc Analyses:** Post-hoc tests, simple slopes, mediation/moderation, subgroup analyses, sensitivity analyses.

### Qualitative Analysis Steps

1. **Familiarization:** Read all data, note initial impressions, write analytical memos.

2. **Coding:** Apply deductive codes from framework and generate inductive codes. Define each code, establish rules, code iteratively. Calculate inter-coder reliability if applicable.

3. **Theme Development:** Group codes into themes, define each precisely, find exemplar quotes (3-5 per theme), map relationships, assess saturation.

4. **Pattern Identification:** Patterns across themes, contradictions, deviant cases.

### Visualization Design Principles

**Chart Type Selection:**
- Bar charts: Compare groups
- Line graphs: Trends, interactions
- Scatterplots: Relationships
- Box plots: Distributions
- Histograms: Single variable distribution
- Pie charts: AVOID (use bar charts instead)

**Design Elements:**
- Clear axis labels with units
- Appropriate scale (don't truncate to exaggerate)
- Error bars (95% CI or SE, clearly labeled)
- Colorblind-friendly palette
- Patterns in addition to colors
- 300 dpi minimum resolution
- Alt text for all visualizations

**Table Formatting:**
- Clear column headers
- Numbers right-aligned, text left-aligned
- Significance noted: *, p < .05; **, p < .01; ***, p < .001
- Footnotes for clarifications
- Consistent formatting throughout

## Structure & Writing

### Document Architecture

**Standard Word Count Allocation (12,000-15,000 words total):**

| Section | Percentage | Word Count |
|---------|-----------|------------|
| Introduction | 10-15% | 1,200-2,000 |
| Literature Review | 20-30% | 3,000-4,500 |
| Theoretical Framework | 10-15% | 1,500-2,200 |
| Methodology (if empirical) | 15-20% | 2,000-3,000 |
| Results (if empirical) | 25-35% | 3,500-5,000 |
| Discussion | 10-15% | 1,500-2,200 |
| Conclusion | 5-8% | 700-1,200 |
| Abstract | -- | 250-350 |

Adjust based on research type, complexity, disciplinary norms, and user requirements.

### Section-by-Section Writing Guide

#### Introduction (1,200-2,000 words)

Structure:
1. **Opening hook** (1 paragraph): Engaging opening - striking statistic, compelling question, real-world scenario, or provocative statement
2. **Context & background** (2-3 paragraphs): Broader context, why area matters, brief historical/theoretical background
3. **Problem statement** (2 paragraphs): Specific problem, why problematic, who it affects, consequences
4. **Research gap** (1-2 paragraphs): What's missing in current knowledge, why gap matters
5. **Purpose & objectives** (1 paragraph): Clear statement of purpose and specific objectives
6. **Research questions** (1 paragraph): Each question stated clearly, numbered list acceptable
7. **Significance & contribution** (2 paragraphs): Why research matters, theoretical and practical contribution
8. **Scope & delimitations** (1 paragraph): What's included/excluded and why
9. **Organization preview** (1 paragraph): "This paper proceeds as follows..."

#### Literature Review (3,000-4,500 words)

**Critical Principles:**
- SYNTHESIZE, don't just summarize
- Organize by THEMES, not by author
- Be CRITICAL, not just descriptive
- Create a NARRATIVE, not a list
- INTEGRATE citations smoothly into prose
- Connect to RESEARCH QUESTIONS throughout

**Correct synthesis approach:**

> Research consistently demonstrates that X occurs across multiple contexts. Early studies established the basic relationship [Smith, 2018; Johnson, 2019], while more recent work has revealed important moderating factors [Jones, 2021]. However, findings differ regarding the strength of this effect, with some studies reporting large effects [Brown, 2020] and others finding modest impacts [Davis, 2022]. These discrepancies may reflect differences in measurement approaches.

**Incorrect (summary) approach - AVOID:**

> Smith (2020) found that X. Jones (2021) also studied X and found Y. Brown (2019) examined X in a different context and found Z.

Structure per theme:
1. Theme introduction (1 paragraph)
2. Literature synthesis (3-5 paragraphs) - group findings, compare/contrast, identify patterns
3. Critical evaluation (1-2 paragraphs) - strengths, limitations, remaining questions
4. Transition to next theme

After all themes:
- Methodological synthesis (1-2 pages)
- Chronological development (if important, 1-2 pages)
- Overall synthesis and critical assessment (2 pages)
- Positioning of current research (1 page)

#### Theoretical Framework (1,500-2,200 words)

1. Introduction - purpose, overview, section organization
2. Theoretical foundations - theory origins, core principles, key assumptions, empirical support, critiques, why chosen
3. Key concepts and definitions - conceptual and operational definitions, relationships, justifications
4. Conceptual model - visual model with caption, detailed explanation, relationship descriptions
5. Analytical framework - how theory guides analysis
6. Assumptions and scope - explicit assumptions, scope conditions, limitations
7. Summary and application - connection to research questions

#### Methodology (2,000-3,000 words, if empirical)

1. Introduction - overview of approach, paradigmatic positioning
2. Research design - type, justification, strengths
3. Sampling - population, strategy, size justification, criteria, recruitment
4. Data collection - methods/instruments, procedures (replication-level detail), pilot testing, quality control
5. Data analysis - approach, techniques, software, assumption testing/trustworthiness measures
6. Validity and reliability - measures taken, threats addressed
7. Ethical considerations - IRB, consent, privacy, risk mitigation
8. Limitations - honest acknowledgment with impact assessment

**Writing style:** Clear, detailed, procedural. Past tense for procedures. Enough detail for replication.

#### Results/Findings (3,500-5,000 words, if empirical)

**Quantitative:**
- Descriptive statistics with Table 1 integration
- Assumption testing summary
- Primary analyses with all statistics reported: "An independent samples t-test revealed a significant difference, t(98) = 3.45, p = .001, d = 0.68, 95% CI [0.25, 1.10]."
- Each table/figure referenced in text before appearance and described
- Post-hoc and additional analyses
- Summary of key findings

**Qualitative:**
- Overview of themes
- For each theme: name, definition, prevalence, exemplar quotes (2-3), interpretation
- Thematic relationships
- Thematic map integration

**Writing style:** Objective, reportorial. Past tense. Separate findings from interpretation. Let data speak.

#### Discussion (1,500-2,200 words)

1. Summary of main findings (1 page)
2. Interpretation in light of literature (3-5 pages) - connect each finding to prior research, offer explanations, consider alternatives
3. Theoretical implications (1-2 pages) - how findings support/challenge/extend theory
4. Practical implications (1-2 pages) - real-world applications, recommendations
5. Unexpected findings (1-2 pages if significant)
6. Limitations (2-3 pages) - expand on methodology limitations, impact on interpretation
7. Strengths (1 page)
8. Future research directions (1-2 pages)

#### Conclusion (700-1,200 words)

1. Synthesis of key findings (no new information)
2. Restatement of contribution
3. Answer to research questions explicitly
4. Broader significance
5. Recommendations (practical, policy, research)
6. Final reflections and closing statement (strong, memorable)

**No new information or citations. Provides closure.**

#### Abstract (250-350 words, write LAST)

Structure:
- Background/context (2-3 sentences)
- Purpose (1-2 sentences)
- Methods (2-3 sentences if empirical)
- Key findings (3-5 sentences, include key statistics or main themes)
- Conclusions/implications (2-3 sentences)
- Keywords (5-7 terms)

Requirements: Self-contained, no citations, concise and dense, represents whole paper.

### Citation Integration Best Practices

- Follow the citation system throughout
- Narrative: Smith (2020) found that...
- Parenthetical: Research shows this pattern (Smith, 2020).
- Multiple sources: Studies demonstrate... (Jones, 2019; Smith, 2020; Taylor, 2021).
- Paraphrase more than quote
- Quote sparingly (< 15 words per quote)
- Include page numbers for direct quotes
- Use signal phrases for variety
- Cite original sources, not secondary
- Don't over-cite common knowledge

### Interdisciplinary Integration (if applicable)

- Give appropriate weight to each discipline
- Bridge different terminologies
- Integrate diverse theoretical traditions
- Address multiple audiences
- Write accessibly for all disciplines
- Consider including a glossary

## Technical Production Specifications

### Page Setup

- **Paper size:** Letter (8.5" x 11") or A4 per discipline
- **Margins:** 1 inch (2.54 cm) all sides
- **Line spacing:** Double-spaced (main text); Single-spaced (block quotes, reference entries)
- **Font:** Times New Roman 12pt (default) or Calibri 11pt, Arial 11pt, Georgia 11pt
- **Paragraph alignment:** Left (not justified)
- **First line indent:** 0.5 inch

### Heading Styles

| Level | Style | Format |
|-------|-------|--------|
| Heading 1 | Main sections | 12pt, Bold, Left, 12pt before / 3pt after |
| Heading 2 | Subsections | 12pt, Bold, Left, 6pt before / 3pt after |
| Heading 3 | Sub-subsections | 12pt, Bold Italic, Left, 6pt before / 3pt after |

Heading hierarchy must be logical: H1 > H2 > H3 with no skipped levels.

### Front Matter Order

1. Title page (no page number)
2. Abstract page with keywords
3. Table of Contents (auto-generated from heading styles)
4. List of Tables (auto-generated from table captions)
5. List of Figures (auto-generated from figure captions)

### Page Numbering

- Front matter: Lowercase Roman numerals (i, ii, iii) or no numbers
- Main body: Arabic numerals starting at 1
- Section break between front matter and main body

### Table Formatting

- Caption ABOVE table: "Table 1: Descriptive Statistics for Sample Characteristics"
- Referenced in text before appearance
- Numbered sequentially
- Borders: Top and bottom only (APA) or full grid per discipline
- Font: 11-12pt
- Table note below if needed (e.g., "Note. N = 150. *p < .05.")

### Figure Formatting

- Caption BELOW figure: "Figure 1. Conceptual model of theoretical relationships."
- Referenced in text before appearance
- Numbered sequentially
- Wrap text: In line with text
- Center aligned
- Alt text added (right-click > Edit Alt Text)
- 300 dpi minimum

### Reference List Formatting

- Starts on new page
- Heading per system: "References" (APA), "Works Cited" (MLA), "Bibliography" (Chicago)
- Hanging indent: 0.5 inch
- Spacing per citation system specifications
- Alphabetized or numbered per system

### Accessibility Requirements

- All images have alt text (1-2 descriptive sentences)
- Proper heading styles applied (not just bold text)
- Document language set (Review > Language)
- Document properties filled (Title, Author, Keywords)
- High color contrast
- Logical reading order
- Run Word's Check Accessibility - goal: no errors

## Common Mistakes to Avoid

1. **Summarizing instead of synthesizing** in the literature review
2. **Organizing literature by author** instead of by theme
3. **Name-dropping theories** without explaining them
4. **Missing citation-reference matching** (orphaned citations or references)
5. **Inconsistent terminology** across sections
6. **Skipping quality gates** to save time
7. **Using justified alignment** instead of left alignment
8. **Missing alt text** on images
9. **Not referencing tables/figures in text** before they appear
10. **Placing table captions below** (should be above) or figure captions above (should be below)
11. **Forgetting to update** Table of Contents and Lists before final delivery
12. **Including unsupported claims** without citations
13. **Overusing direct quotes** instead of paraphrasing
14. **Producing PDF** instead of the required .docx format
15. **Proceeding to writing** before synthesis is fully complete and approved
