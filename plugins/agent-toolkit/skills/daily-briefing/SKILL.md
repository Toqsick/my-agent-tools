# Daily Briefing

## Overview

A Daily Briefing is a 60-second summary of: system status, open items,
recent activity, and recommended next step. It is run at session start
(after a break > 4h), at the user's request, or when context is unclear.

## Sections

1. **System Status** — agents available, skills loaded, current workspace
2. **Open Items** — pending tasks, unanswered questions, blocked items
3. **Recent Activity** (last 24-72h) — what was done, by whom, with what
   outcome
4. **Recommended Next Step** — concrete action for the user to take

## When to use

- Session start after a break
- User asks "wo standen wir?" / "what's the status?"
- Before planning the next major work block

## When NOT to use

- Mid-task (would break flow)
- For trivial single-action sessions
